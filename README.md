# 双人旅行计划工作台

一个给 **两个人实时协作** 的旅行规划工具：按天排行程、地图上按真实道路画路线、智能排序、每个站点和每一天都能放图和小红书链接、还能在任意点/天里讨论。

---

## 一、功能速览

- **实时协作**：两个人开同一个链接，谁改了另一边立刻看到；顶部显示在线旅伴、每条改动标注是谁做的。
- **行程规划**：按「天」组织（Day 1、Day 2…）；地图上可看「全程」或一键切到「某一天」。
- **地图路线（最接近导航）**：
  - 顶部搜索地点 → 自动地理编码成坐标 → 加入当天行程；
  - 或点「📍 地图选点添加」直接在地图上打点；
  - 每段路线之间有「交通方式」按钮（自驾/高铁/步行/公交/飞机），可手动选；系统也会按距离给出建议方式和预估用时；
  - **自驾/步行** 画真实道路线（开发期用免费路由，填高德 Key 后更准）；**高铁/飞机** 画两站连线 + 车次标签。
- **智能排序**：每天可单独用「最短时间」或「最短距离」一键重排；可指定某点为当天起点（如酒店）。
- **图文 + 小红书**：每个站点、每一天都能加图（贴网址 或 手机上传）和小红书跳转链接。
- **讨论区**：每个站点、每一天都能留言，两人实时聊「去不去」。
- **多次旅行**：支持新建/切换/删除多个行程。

## 二、本地运行

```bash
# 1) 安装依赖（需要 Node 18+）
npm install

# 2) 启动（默认 3000 端口）
npm start
# 或自定义端口：
PORT=8080 npm start

# 3) 浏览器打开
open http://localhost:3000
```

> 开发期无需任何 Key：地图底图用 OpenStreetMap，道路路线用免费 OSRM，地理编码用 Photon。两人本地协作时，连同一个 WiFi 直接互访 `http://<你的内网IP>:3000` 即可。

## 三、接入高德地图（推荐，路线更准）

开发期已能跑通，但想让道路路线、地点搜索达到「导航 App」级别，建议接入高德：

1. 打开 https://lbs.amap.com/ 注册 → 进入「应用管理 → 创建应用 → 添加 Key」。
2. 服务平台选 **「Web 端 (JS API)」**（地图展示）和 **「Web 服务」**（服务端路线/地理编码都走服务端代理，Key 不暴露给前端）。
3. 用环境变量把 Key 注入后重启：

```bash
AMAP_KEY=你的高德Key npm start
```

服务端会自动切换到高德：自驾/步行/公交走高德路线规划（真实道路线），地理编码走高德（国内地名识别更准）。未设置时自动回退到免费方案。

## 四、让两人异地也能用（公网访问）

本工具是「前端 + Node 后端（WebSocket 实时同步 + JSON 数据库）」，要两人不同网络协作，必须有一个公网可访问的地址。三种方式：

### 方式 A：临时隧道（最快，session 级）
在本机执行（任选其一，均免账号）：
```bash
# serveo（免密钥，推荐）
ssh -R 80:localhost:3000 serveo.net
# 或 localhost.run（需先生成并添加 SSH 公钥到其账号）
ssh -R 80:localhost:3000 ssh.localhost.run
```
终端会给出一个 `https://xxxx` 公网地址，两人手机打开即用。隧道随本机/会话结束失效。

### 方式 B：部署到 Railway（永久、免费额度）
1. 把本目录推到 GitHub 仓库；
2. 打开 https://railway.app → New Project → 选该仓库；
3. 在 Variables 里加 `AMAP_KEY`（可选）；
4. 部署完成会得到一个永久 `https://xxx.up.railway.app` 地址。
（已附 `package.json` 与 `Procfile`，Railway 会自动识别 `npm start`。）

### 方式 C：部署到 Render（永久、免费额度）
1. 推到 GitHub；
2. 打开 https://render.com → New → Web Service → 选仓库；
3. Build Command `npm install`，Start Command `node server.js`；
4. 在 Environment 里加 `AMAP_KEY`（可选）；
5. 部署后得到永久地址。
（已附 `render.yaml`，可直接 "Blueprint" 导入。）

## 五、数据存储与备份

- 所有行程存在 `data/db.json`（JSON 文件），修改即时落盘。
- **备份**：直接复制 `data/db.json` 即可。
- **注意**：Railway / Render 免费实例的磁盘通常是**临时**的，重启或重新部署可能清空本地文件。如需行程长期保存，建议：
  - 用平台的「Volume / 持久盘」把 `data/` 挂上去；或
  - 定期把 `data/db.json` 下载备份。
- 本 session 内通过隧道访问时，数据就存在这个运行实例里，正常保存。

## 六、给协作者的一句话上手

1. 打开链接 → 点右上角「改名」填你的昵称；
2. 用顶部搜索框加地点，或点「📍 地图选点添加」在地图上打点；
3. 点每段之间的交通按钮选「自驾/高铁…」并看建议；
4. 需要重排就点当天「⚡最短时间排序」；
5. 在站点/当天的「详情」里贴图、加小红书链接、留言讨论。

两人看到的画面完全实时同步。玩得开心 🧭

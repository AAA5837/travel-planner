# 双人旅行计划工作台

一个给 **两个人实时协作** 的旅行规划工具：按天排行程、地图上按真实道路画路线、智能排序、每个站点和每一天都能放图和小红书链接、还能在任意点/天里讨论。

---

## 一、功能速览

- **实时协作**：两个人开同一个链接，谁改了另一边立刻看到；顶部显示在线旅伴、每条改动标注是谁做的。
- **行程规划**：按「天」组织（Day 1、Day 2…）；地图上可看「全程」或一键切到「某一天」。
- **地图路线（最接近导航）**：
  - 顶部搜索地点 → 自动地理编码成坐标 → 加入当天行程；
  - 或点「📍 地图选点添加」直接在地图上打点；
  - 每段路线之间有「交通方式」按钮（自驾/高铁/步行/公交/飞机），可手动选；系统也会按距离给出建议方式和预估用时；
  - **自驾/步行** 画真实道路线（开发期用免费路由，填高德 Key 后更准）；**高铁/飞机** 画两站连线 + 车次标签。
- **智能排序**：每天可单独用「最短时间」或「最短距离」一键重排；可指定某点为当天起点（如酒店）。
- **图文 + 小红书**：每个站点、每一天都能加图（贴网址 或 手机上传）和小红书跳转链接。
- **讨论区**：每个站点、每一天都能留言，两人实时聊「去不去」。
- **多次旅行**：支持新建/切换/删除多个行程。

## 二、本地运行

```bash
# 1) 安装依赖（需要 Node 18+）
npm install

# 2) 启动（默认 3000 端口）
npm start
# 或自定义端口：
PORT=8080 npm start

# 3) 浏览器打开
open http://localhost:3000
```

> 开发期无需任何 Key：地图底图用 OpenStreetMap，道路路线用免费 OSRM，地理编码用 Photon。两人本地协作时，连同一个 WiFi 直接互访 `http://<你的内网IP>:3000` 即可。

## 三、接入高德地图（推荐，路线更准）

开发期已能跑通，但想让道路路线、地点搜索达到「导航 App」级别，建议接入高德：

1. 打开 https://lbs.amap.com/ 注册 → 进入「应用管理 → 创建应用 → 添加 Key」。
2. 服务平台选 **「Web 端 (JS API)」**（地图展示）和 **「Web 服务」**（服务端路线/地理编码都走服务端代理，Key 不暴露给前端）。
3. 用环境变量把 Key 注入后重启：

```bash
AMAP_KEY=你的高德Key npm start
```

服务端会自动切换到高德：自驾/步行/公交走高德路线规划（真实道路线），地理编码走高德（国内地名识别更准）。未设置时自动回退到免费方案。

## 四、部署到 Render（永久公网地址 · 推荐）

> 前提：代码必须先在一个 **GitHub 仓库** 里（Render 从 Git 拉取，不支持直接上传文件夹）。你需要一个 GitHub 账号 + 一个 Render 账号，均为免费。

**第 1 步：把代码推到 GitHub（你来做）**
1. 注册/登录 GitHub（https://github.com）。
2. 新建一个**空仓库**（不要勾选 README / .gitignore），例如 `travel-planner`。
3. 在本项目目录执行（把 URL 换成你自己的仓库地址）：
   ```bash
   git remote add origin https://github.com/你的用户名/travel-planner.git
   git push -u origin main
   ```
   > 首次 push 需要 GitHub 认证：本地有 SSH key 就用 SSH 地址；否则用 HTTPS 并按提示输入「用户名 + 个人访问令牌（token，不是账号密码）」。

**第 2 步：在 Render 一键部署（你来做）**
1. 注册/登录 Render（https://render.com）。
2. 右上角 **New → Blueprint**，授权连接你的 GitHub，选择 `travel-planner` 仓库。
3. Render 会读取本项目的 `render.yaml` 自动建好 Web Service（无需手填 Build/Start 命令）。
4. 可选：在 Environment 里加 `AMAP_KEY`（高德 Key，不填也能跑，只是路线精度低一些）。
5. 点 **Deploy**，约 1–2 分钟后得到永久地址：`https://travel-planner-xxxx.onrender.com`，两人手机打开即用。

**临时隧道（session 级，最快但不持久）**
如果不想注册账号，本机执行 `ssh -R 80:localhost:3000 serveo.net`（免密钥）即可拿到一个 `https://xxxx` 临时公网地址。缺点：地址会过期、有英文警告页，仅适合临时演示。

## 五、数据存储、备份与恢复

- 所有行程存在 `data/db.json`（JSON 文件），修改即时落盘。
- **⚠️ 重要：Render / Railway 免费实例的磁盘是临时的**，每次重新部署或实例重建都会清空 `data/`，行程数据会丢。两种应对方式（推荐组合使用）：
  1. **用界面上的「⬇ 备份 / ⬆ 恢复」按钮**：点「⬇ 备份」把全部行程下载成 JSON 存到手机/电脑；要恢复时点「⬆ 恢复」选该文件即可。重新部署前记得备份一次。
  2. **挂持久盘（Render 付费 plan 支持）**：给该服务挂一个 Disk 并挂载到 `/data`，把 `data/` 指向它，可彻底持久化（需要改少量配置，需要时可帮你做）。
- 本 session 内通过隧道访问时，数据就存在运行实例里，正常保存，无需备份。

## 六、给协作者的一句话上手

1. 打开链接 → 点右上角「改名」填你的昵称；
2. 用顶部搜索框加地点，或点「📍 地图选点添加」在地图上打点；
3. 点每段之间的交通按钮选「自驾/高铁…」并看建议；
4. 需要重排就点当天「⚡最短时间排序」；
5. 在站点/当天的「详情」里贴图、加小红书链接、留言讨论。

两人看到的画面完全实时同步。玩得开心 🧭
